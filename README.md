# TechStore - Componentes de PC

## Propósito de la página

TechStore es una tienda online de componentes de PC (placas de video, procesadores, memorias RAM, almacenamiento y motherboards). El sitio permite:

- Ver los productos disponibles con precios actualizados
- Conocer la tienda y su propuesta
- Enviar consultas a través de un formulario de contacto
- Navegar entre las secciones Inicio, Productos, Reseñas y Contacto

## Tecnologías usadas

- HTML5 - estructura semántica
- CSS3 - estilos, Flexbox, Grid y Media Queries
- Google Fonts - tipografía Poppins
- Formspree - envío del formulario de contacto
- Google Maps - ubicación de la tienda

## Estructura del proyecto

- index.html - Página principal
- css/styles.css - Estilos del sitio
- img/ - Imágenes del sitio
- pages/contacto.html - Página de contacto
